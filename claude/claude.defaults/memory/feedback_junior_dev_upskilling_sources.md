When pitching feedback at a junior developer level, always include at least
one upskilling source.

**Why:** User wants junior-level explanations to actively build skills, not
just solve the immediate problem.

**How to apply:**
- Source preference order:
  1. Official documentation (MDN, Node.js docs, npm docs, OWASP, language
     specs, RFC, etc.)
  2. Industry-respected source (Google Security Blog, Trail of Bits, Snyk
     blog, etc.) — only if no relevant official docs exist
- Never link to generic blog posts when an official doc covers the topic
- Include the source naturally at the end of the explanation or inline
  where it's most relevant
